# 后续工作与已知边界

当前已完成原生输入下的基础规则 Co-TDMA 和每 AP 独立状态输出；规则、使用方法及已通过检查见 [BASIC_NATIVE_COTDMA.md](BASIC_NATIVE_COTDMA.md)。下列内容是后续工作，不属于当前已实现能力。

## 基础 Co-TDMA 继续验证

- 扩展更长时段、更多 seed、更多拓扑及干扰组合；现有专项已经覆盖多 AP、多组、不同 STA 数、带宽不对称、丢帧和守恒。
- 固定节点 ID 的旧 AUDIT 诊断仍需通用化；当前稳定观测入口是每 AP JSONL。
- 原生多 AC、完整标准 NAV/CF-End 生命周期与更完整的协议一致性需独立设计和验证；不直接开启历史 replay 路径代替原生适配。

## 后续 Agent 接口

- 继续一 AP 一 Agent，每个 Agent 读取本 AP 状态，不建立全网状态汇总。
- 目前只有事件观测；动作提交、仿真暂停/步进、动作生效时点及因果顺序尚未实现。
- Agent 接入前先明确动作可行性和规则回退，再设计训练/评估；当前不进行学习。

## Co-SR

已有官方四种功率策略、本地控制帧接收修复、功率缓存和不可行时分回退传播；尚未完成完整正确性验证。

后续核对各策略的功率单位、总功率/每信道口径、预计与实际 SINR、跨轮次恢复，以及双方可行/单方不可行/均不可行时的状态、padding、ACK、NAV 和超时。先通过解析功率/SINR 对照及闭环检查，再比较性能。

## Co-BF

已有仅 Co-BF 自动零陷及期望/零陷退化保护。已知 Gram 矩阵固定步长 5 构造、求解器按实际 M 读取的问题尚未修复。

后续先修复矩阵布局并做独立数值参考测试，再验证共轭、归一化、主瓣/零陷、功率守恒和奇异矩阵回退，最后验证实际 DATA/ACK 干扰及协议闭环。真实 sounding、CSI 老化和多径 MIMO 属于另行扩展。

## 历史输入兼容

官方 high_density_scenarios 中 13 份节点输入采用旧 destination_id/tpc/cca 字段布局，当前不能直接读取。后续应明确格式版本和字段语义，生成独立迁移文件并验证；官方原输入继续保留。
